# e-Commerce 행동 데이터 파이프라인 구성 및 시각화
Kaggle의 OTTO e-commerce 데이터셋을 활용한 실시간 데이터 파이프라인

## 프로젝트 목적
OTTO 이커머스의 대규모 클릭스트림 데이터를 안정적으로 수집하고 가공하여, 데이터 기반의 실시간 의사결정을 지원하는 파이프라인. 
단순한 데이터 이동을 넘어 대용량 로그의 정합성을 보장하고 분석 가능한 형태로 자산화하는 인프라를 구축하고, 시각화 대시보드와 데이터 파이프라인 알림체계까지 구축하고자 함.

## 프로젝트 목표
1. 파이프라인 안정성 및 정합성 확보
- Kafka 클러스터: 1~3 Broker 구성으로 장애 발생 시에도 데이터 유실이 없는 내결함성을 구현.
- 데이터 거버넌스: Schema Registry를 통해 규격에 맞는 데이터만 수집하여 파이프라인의 데이터 데이터 정합성 확보.

2. 데이터 적재 및 배치 처리의 효율성 확보
- 적재 효율 확보: Kafka Connect를 활용해 원본 JSON을 S3에 Parquet 포맷으로 변환 적재함으로써 저장 비용 절감과 쿼리 성능을 동시에 확보.
- 데이터 마트 고도화: Spark와 Airflow 3.0을 연동하여 복잡한 세션 로그를 분석및 시각화 대시보드에 적합한 형태로 집계하고, 이를 Postgre에 데이터 마트 형태로 적재.

3. 파이프라인 모니터링
- 실시간 옵저버빌리티: Prometheus/Grafana와 Slack을 연동하여 시스템 상태와 지연(Lag)을 실시간으로 모니터링.
- 비즈니스 지표 시각화: Metabase를 통해 구매 전환율과 실시간 트렌드 등 핵심 지표를 즉각적으로 확인할 수 있는 환경을 제공.

## 프로젝트 진행 순서

#### 1단계: 인프라 구축 및 원천 데이터 분석
- 환경 구성: 가상 머신(VM) 및 도커(Docker) 기반의 인프라 환경 구축.
- 데이터 분석: 12GB 규모의 OTTO JSONL 데이터 구조 파악 및 샘플링(1,000건).
- 저장소 준비: PostgreSQL 데이터베이스 및 S3 저장소 구축.

#### 2단계: 실시간 데이터 수집 레이어 구현
- Producer 개발: 파이썬 기반의 데이터 재현(Replay) 프로듀서 구현.
- Schema Registry: Avro 스키마 정의 및 데이터 정합성 검증 로직 적용.
- Kafka Cluster: 1 Broker 클러스터 구성 및 토픽 최적화(이후 3 Broker까지 유동적으로 변환).

#### 3단계: 데이터 적재 및 배치 처리
- Kafka Connect: S3 Sink 커넥터를 활용하여 Raw 데이터를 Parquet 포맷으로 실시간 적재.
- Spark ETL: S3에 저장된 데이터를 Spark로 읽어와 세션 기반 평탄화 및 마트 가공.
- Data Mart: 분석용 PostgreSQL 테이블 설계 및 가공 데이터 적재.

#### 4단계: 워크플로우 자동화 및 모니터링
- Airflow 3.0: Spark 잡(Job) 실행 및 데이터 마트 갱신 스케줄링 자동화.
- Monitoring: Prometheus/Grafana를 통한 카프카 상태 시각화.
- Alerting: 장애 감지 시 Slack 채널로 실시간 알림 연동.

#### 5단계: 시각화 및 프로젝트 마무리
- Dashboard: Metabase를 활용한 주요 비즈니스 지표(전환율, 인기 상품 등) 시각화.
- Performance Tuning: 전체 파이프라인의 처리 속도 및 리소스 사용량 최적화.
- Documentation: 최종 결과 보고 및 README 업데이트.
