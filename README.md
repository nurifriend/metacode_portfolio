# e-Commerce 행동 데이터 파이프라인 구성 및 시각화
Kaggle의 OTTO e-commerce 데이터셋을 활용한 실시간 데이터 파이프라인

## 프로젝트 목적
- 데이터 파이프라인 구축 : 대용량 데이터(약 12GB) 처리를 위해 Kafka, Spark, Airflow등을 조합한 파이프라인 구축
- 유저 행동 추적: 수백 만 건의 세션별 클릭, 장바구니, 구매 이벤트를 수집하여
- 세션 기반 데이터 통합: 비식별화된(고객 식별정보 없음) 세션 데이터를 분석 가능한 형태로 구조화하여, 고객 행동(클릭, 장바구니)과 최종 구매 간의 관계를 시각화

## 프로젝트 목표
✅ 기술적 목표 (Technical Milestones)
- Kafka를 활용하여 데이터 유실없이 대량의 데이터를 안정적으로 S3에 적재
- 로우(Raw) 데이터인 JSONL의 중첩 구조를 BigQuery 내에서 평탄화(Flattening)하고, 상품 메타데이터와 결합하여 분석 최적화된 마트를 구축합니다.

Workflow Automation: Airflow 3.0을 통해 전체 파이프라인의 의존성을 관리하고, 장애 발생 시 자동 재시도 및 알림 시스템을 구축합니다.

✅ 비즈니스 분석 목표 (Analytical Milestones)
실시간 퍼널 분석: Click ➔ Cart ➔ Order로 이어지는 단계별 전환율을 실시간으로 집계하여 이탈 지점을 파악합니다.

인기 상품 트렌드 도출: 특정 시간 윈도우(Window) 내에서 클릭률이 급증하는 상품(Trending Items)을 식별하여 재고 관리 및 마케팅 전략의 근거를 마련합니다.

세션 가치 측정: 평균 체류 시간 및 세션당 이벤트 수를 분석하여 사용자 인게이지먼트 지표를 정량화합니다.
